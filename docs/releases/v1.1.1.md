# Chameleon v1.1.1 · 溶图

维护版本：清理工程、移除无效代码与资源，并补上两处交互反馈。**融合功能与 v1.1.0 完全一致**。

## 可见改进

- **首页读取反馈**：选好图片后显示「正在读取并分析照片…」进度条（此前解码与抠图期间界面没有任何提示）。
- **场景摘要更完整**：编辑器顶部的摘要新增「细节丰富 / 细节适中 / 画面柔和」一项。

## 清理（不影响功能）

- 删除 **15 处从未被引用**的死代码：`BlendEngine.defaultParams / detailOf / coverage`、`ColorMath.toLabPlanes / fromLabPlanes / colorDistance / nearlyEqual`、`ImageOps.blurGaussian / dilate`、`RasterImage.sampleNearest`、`ParallelRows.parallelism`、`Controls.SoftDivider / TransparentScrim`、`EditorViewModel.startNew`、主题里未使用的强调色。
- 移除只写不读的状态（`EditorState.autoTuned`）与已失效的常量（`PREVIEW_MAX` / `QUICK_MAX`）。
- **性能**：色彩迁移里算了却不使用的 `fgBands` 移除，每次渲染少一次全图 Lab 转换。
- **依赖**：移除 3 个没用到的依赖（`lifecycle-runtime-ktx`、`compose ui-tooling`、`ui-tooling-preview`）。
- **资源**：删除 minSdk 29 下永远不可达的 5 档传统图标位图（10 个文件 / 310 KB）；`tools/generate_icon.ps1` 新增 `-LegacyBitmaps` 开关，仅在 minSdk < 26 时才需要。
- **规范**：`Bitmap.scale`、`SharedPreferences.edit` 改用 KTX 扩展；新增 `app/lint.xml` 消除 `mipmap-anydpi-v26` 的过时提示。Lint 现在只剩「有更新版本可用」这类版本提示。

## 仓库维护

- 重写 Git 历史，清除早期误提交的构建产物（`app/build/**`、`app/release/**`、`.idea/**`）。
- **全新 clone 体积从 54.4 MB 降到 2.2 MB**，代码内容与之前的提交完全一致（文件树校验相同）。

## 安装

1. 下载下方 Assets 中的 APK；
2. 允许「安装未知来源应用」后安装；
3. 系统要求：**Android 10（API 29）及以上**。

> 与 v1.0.0 / v1.1.0 使用**同一签名密钥**，可直接覆盖升级（本次 versionCode 2）。
