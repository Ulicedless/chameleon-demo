# Chameleon v1.1.0 · 溶图

把二次元角色自然地「溶」进现实照片：匹配场景光源方向、色温、噪点与投影，让角色看起来真的站在那个场景里。
全部处理在本机完成，不联网、不上传图片。

> 这一版重写了地面投影与色彩匹配模型，修复了「第一次导出成功、之后失败」的问题，并加入沉浸式全屏预览与设置页。

## ✨ 新增

- **沉浸式全屏预览**：双指缩放、拖动平移、双击复位、单击隐藏界面，预览内可随时切换「看原图 / 看融合后」，退出自动恢复系统栏。
- **设置页**：主题（跟随系统 / 浅色 / 深色）、动态取色、是否自动识别场景风格、默认风格、融合强度、预览质量（720 / 1024 / 1280）、导出默认分辨率与格式与质量、抠图默认值、保留作品、构图参考线、缓存清理。
- **8 种风格预设**：自然、影棚、日光、黄昏、夜景、逆光、插画、胶片。
- **导出与分享**：1280 / 1920 / 2560 px，JPG 或 PNG，保存到相册（`Pictures/Chameleon`）或直接分享。
- **最近作品**：原图、参数、抠图设置一并保存，可重新打开继续编辑。

## 🎨 算法

**地面投影（重写）**：旧版把角色沿光向往屏幕下方推，影子会「往下掉」并提前消失。现在按「离地高度 h → 沿地面远离光源 h / tan(仰角)」投影，再用相机俯仰压缩系数压回地面，影子贴地延伸，近处更实、远处更虚（半影随距离增长，核心不衰减）。

**色彩融合（升级）**：色彩迁移改为在 CIELAB 空间按**阴影 / 中间调 / 高光分段**匹配背景统计量，并新增「高光 / 阴影配色」——角色自身的高光染上场景主光的颜色、暗部染上环境光的颜色。

**边缘净化（新增）**：把半透明边缘里残留的背景色用画稿内部颜色替换（松弛扩散，越透明替换越多），消除抠图常见白边 / 彩边。

**抠图（升级）**：距离直方图改用 Otsu 阈值，并做两次导向滤波（宽 + 紧），连通域保护可保留画稿内部的同色区域（例如白衬衫）。

## 🐛 修复

- **修复「第一次导出成功、之后一直提示导出失败」**：选图返回的 `content://` URI 读权限只在本次会话内有效，会话结束后重新解码必然失败。现在选图后立即把原图复制到应用私有目录，导出只读自己的副本。
- **内存不足自动降级**：2560 → 1792 → 1254，最终退到用内存里已有的预览图导出，并提示实际导出的分辨率，而不是直接失败。
- **相册写入兜底**：MediaStore 被系统拒绝时改写到应用专属目录并提示位置。
- **导出流程不再卡住**：全部包在 try / catch / finally 中，失败会给出具体原因，按钮不会停留在「导出中」；导出期间屏幕保持常亮。
- **启动器图标**：由单张图生成自适应前景 / 背景 + 单色层 + 5 档密度方块与圆形位图，修复了方形图标全出血与圆形图标形状错误的问题。

## 📲 安装

1. 下载下方 Assets 中的 APK；
2. 允许「安装未知来源应用」后安装；
3. 系统要求：**Android 10（API 29）及以上**。

> ⚠️ 本版 APK 与 v1.0.0 使用同一个签名密钥，可直接覆盖升级；如果之前装过其他来源的同包名版本（`com.chameleon.blend`），可能需要先卸载。

## ⚠️ 已知限制

- 导出 2560 px 在低内存机型上可能触发降级（会提示实际分辨率）；
- 复杂背景（发丝、半透明衣料、杂乱纹理）的自动抠图效果有限，建议使用透明底 PNG 立绘；
- 目前仅中文界面。
